>
> 状态图例：✅ 已实现　◐ 部分实现　⬜ 未实现

## 1. 背景与目标

系统品牌由"AI CRM"更名为 **榜样CRM**（✅ 已完成）。现有知识库仅为单层文档列表，无法支撑企业级使用。本规格参考业界优秀方案（MaxKB「知识库—文档—分段」三级模型、Dify datasets、FastGPT 集合/目录、PandaWiki 多知识库站点），将知识管理能力升级为：

1. **多知识库**：可创建任意多个知识库，各自独立管理文档与检索范围 ✅
2. **文档库（文件中心）**：独立的文件资产管理区，文件/文件夹先行入库，再按需关联到一个或多个知识库 ✅
3. **客户文档与画像**：客户相关的合同、协议、访谈纪要、录音等资料集中归档，AI 自动生成客户画像，并为每个客户提供**专属知识库问答** ✅

## 2. 业界参考结论

| 系统 | 可借鉴设计 |
|---|---|
| MaxKB | 知识库 → 文档 → 分段三级模型；文档解析状态机；按知识库隔离检索 |
| Dify | 文件先入库存储、再被 dataset 引用；检索时可指定 dataset 范围 |
| FastGPT | 知识库内文件夹组织；一个文件可被多处引用 |
| PandaWiki | 多知识库独立门户；网页/第三方来源导入（后续扩展项） |

核心共识：**文件资产与知识库解耦**——文件只存一份，知识库存的是"引用 + 解析后的切片"，检索按知识库过滤。

## 3. 概念模型

```
文档库（文件中心）                    知识库
├── 文件夹（树形，任意层级）          ├── 知识库A（通用）
│   └── 文件（任意格式，仅存一份） ──关联──▶│   └── 文档（引用文件+解析切片）
│                                     ├── 知识库B（通用）
└── 文件  ──关联─────────────────────▶│   └── 文档 …
                                      └── 客户专属知识库（每客户自动创建）
客户                                   └── 文档（客户合同/协议/访谈/录音）
└── 客户文件（上传即入文档库并自动关联专属知识库）
```

- **文件（library_file）**：物理资产，全局唯一存储，记录文件夹归属、可属客户 ✅
- **知识库（knowledge_base）**：逻辑集合，type = general / customer（客户专属） ✅
- **文档（kb_document）**：文件在某知识库中的引用；解析（切片+向量化）发生在关联到知识库时 ✅
- 一个文件可关联多个知识库；从知识库移除文档不删除文件本身 ✅

## 4. 功能需求

### FR-1 知识库管理
- FR-1.1 创建/重命名/编辑描述/删除知识库；删除知识库级联删除其文档与切片，**不影响文档库文件** ✅
- FR-1.2 知识库列表展示：名称、描述、文档数、切片数、类型（通用/客户专属） ✅
- FR-1.3 知识库详情：文档列表（解析状态、切片数）、关联新文件、移除文档、查看切片 ✅

### FR-2 文档库（文件中心）
- FR-2.1 文件夹树形管理：创建/重命名/移动/删除（含递归删除），任意层级 ◐ 已实现，但文件夹删除目前为**物理删除**，不进入八期新增的回收站（见第 9 章后续规划）
- FR-2.2 文件上传：**支持上传整个文件夹**（保留目录结构自动建文件夹）；**所有格式均可上传**（含图片、音频 mp3/wav/m4a、压缩包等），文档格式（pdf/docx/txt/md）与**图片/音频/视频（十期多模态识别转写，见第 8 章）**在关联知识库时解析，其余标记"仅存储" ✅
- FR-2.3 文件列表：按文件夹浏览 + 全局关键词搜索；展示格式、大小、支持与否、关联的知识库数 ✅
- FR-2.4 文件操作：重命名、移动文件夹、删除；**设置知识库关联**（单个或批量，可关联到多个知识库） ✅
- FR-2.5 上传时自动关联：上传对话框可选目标知识库，上传完成即自动关联并触发解析 ✅

### FR-3 客户文档与专属知识库
- FR-3.1 每个客户自动拥有一个专属知识库（type=customer，首次访问自动创建，命名"客户名-专属知识库"） ✅
- FR-3.2 客户详情新增"客户文档"页签：上传/查看该客户的合同、协议、访谈纪要、录音等；客户文件上传后**自动关联进专属知识库**（支持的格式自动解析；十期起录音等音视频由 ASR 自动转写入库，此前"人工上传转写文本 txt"的临时方案不再必需） ✅
- FR-3.3 客户文件同时出现在文档库（按客户过滤），可在文档库中将其追加关联到其他通用知识库 ✅

### FR-4 客户画像（AI）
- FR-4.1 基于客户全部资料（基本信息、跟进记录、商机、已解析的客户文档内容）由 LLM 生成结构化客户画像（Markdown：基本情况/需求痛点/决策链/合作进展/风险与建议） ✅
- FR-4.2 画像异步生成，状态机 idle/generating/ready/failed；可手动重新生成；LLM 未配置时 failed 优雅降级 ✅
- FR-4.3 客户详情"画像"页签展示生成结果与时间 ✅

### FR-5 按知识库范围的问答
- FR-5.1 问答接口（/chat/ask、/chat/ask/stream、/rag/query）支持 kb_ids 参数限定检索范围；不指定则检索全部知识库 ✅
- FR-5.2 AI 工作台顶部提供知识库多选器（chips/下拉），选客户专属库即实现"专属问答" ✅
- FR-5.3 客户详情提供"专属问答"入口：跳转 AI 工作台并自动选中该客户的专属知识库 ✅（九期起另有内置"AI 对话"页签，客户主页内直接完成专属问答，见第 8 章）

### FR-6 品牌更名
- 全站名称改为"榜样CRM"：浏览器标题、登录页品牌区、侧边栏 Logo 区、README 与技术文档 ✅

## 5. 交互与体验要求

- 知识库页与文档库页作为"知识库"菜单下两个页签（或并列菜单），视觉风格与三期一致（卡片、状态 tag、抽屉详情） ✅
- 文件夹上传使用 `webkitdirectory`；上传过程显示进度与结果汇总（成功 N 个/仅存储 M 个） ✅
- 文档库左侧文件夹树 + 右侧文件列表的经典双栏布局，移动端折叠为抽屉 ✅
- 解析状态沿用现有轮询机制（processing 每 3 秒刷新） ✅
- 全站响应式与主题系统（明暗/品牌色）对新页面同样生效 ✅

## 6. 非功能要求

- 旧数据迁移：现有 knowledge_documents 自动迁移为"默认知识库 + 文档库文件 + 关联文档"，幂等执行，不丢数据 ✅
- 所有新接口保持租户隔离与 JWT 鉴权；LLM/存储不可用时优雅降级 ✅
- 新增核心逻辑（格式判定、目录结构解析、画像 Prompt 构建、kb 过滤检索）必须有 pytest 覆盖，全量测试保持全绿 ✅（当前 256 个用例全绿）

## 7. 验收标准

1. 可创建多个知识库并各自关联不同文件；同一文件可关联多个知识库 ✅
2. 文件夹整体上传后目录结构保留；txt/md 正常解析，mp3/zip 等标记"仅存储"不报错 ✅
3. 客户上传合同后，其专属知识库自动出现该文档并（LLM 可用时）解析为可检索切片 ✅
4. AI 工作台选择"张三-专属知识库"后，问答仅基于该客户资料并带引用 ✅
5. 客户画像可生成/重新生成，LLM 未配置时状态为 failed 且不影响其他功能 ✅
6. 全站品牌显示为"榜样CRM" ✅

## 8. 实现增量（五~十二期新增能力，超出 v1.0 范围）

以下能力在四期验收后陆续实现，作为本系统现行功能基线：

- **系统管理端**（五期）：用户/用户组管理；LLM 模型注册（数据库配置优先于环境变量；支持拉取远端模型列表与保存前试连通）与调用用量统计（echarts 图表）；后端异常日志页
- **在线预览**（六期）：文档库/客户文档支持 docx（mammoth 转 HTML）、PDF、图片、音视频、Markdown、纯文本在线预览；RAG 命中测试工具（输入问题查看召回切片与得分）
- **行业标签**（七期）：行业字典维护，客户可打行业标签，档案信息增强
- **回收站**（八期）：客户/库文件/知识库软删除（`deleted_at`），管理端回收站支持恢复与彻底删除（客户连带专属知识库；知识库文档移除与文件夹删除仍为物理删除）
- **客户数据工具**（八期）：客户 Excel 导入导出（openpyxl）、客户查重（名称/联系方式相似度）
- **操作审计**（八期）：`audit_logs` 记录关键操作（action / resource_type / resource_id / detail / ip），管理端可查询
- **安全加固**（八期）：单文件上传上限（`MAX_UPLOAD_MB=100`，超限 413）、CORS 显式白名单、安全响应头、非 dev 环境弱 JWT 密钥拒绝启动
- **多轮对话与工作流**（三期，先于四期完成）：会话管理、问题改写指代消解、自动追问建议；工作流五类触发器（客户创建/状态变更/商机阶段变更/跟进新增/定时）与任务/通知/邮件动作
- **客户主页 AI 对话**（九期）：客户详情新增"AI 对话"页签，懒加载锁定该客户专属知识库（kb_ids），与 AI 工作台同款气泡/流式/Markdown/停止按钮体验；内置四个快捷提问（介绍客户/喜欢什么/最近沟通/风险与机会），空资料引导文案，LLM 未配置时错误帧友好展示
- **引用来源直达**（九期）：问答/对话的 sources 经 `attach_file_info()` 批量回填文件信息（file_id/file_name/file_type/file_size，最多 2 次查询无 N+1；文件缺失或已软删时为 None 并保留 doc_title），前端 CustomerDetail 与 Chat 的来源项可点击打开 FilePreview 在线预览
- **多模态摄入管线**（十期）：解析格式由文档扩为四类——图片（视觉模型转录文字+描述内容）、扫描版 PDF（pypdf 字符过少时 pymupdf 逐页渲染 + 视觉识别，限 50 页）、音频（ASR 转写，whisper 兼容接口）、视频（ffmpeg 抽音轨再 ASR）；产出带 [图片识别]/[扫描件识别]/[音频转写]/[视频转写] 前缀并记录处理方式（processing_method：text/vision_ocr/image_describe/asr/video_asr）与所用模型；任何失败只标 failed 不阻塞上传
- **LLM 模型类型扩展**（十期）：模型注册 model_type 扩为 chat/embed/vision/asr 四类（后续再增 rerank 重排序，共五类：注册后检索精排走"专用 rerank 模型 → chat LLM 打分 → RRF 序"三级降级，未配置时行为不变）；vision 未配置时回退 chat 默认模型（不支持图像则以 failed 降级写明原因），asr 未配置时音视频转写降级 failed；LLM 层新增 transcribe/rerank 并统一用量埋点；生产建议注册 vision（qwen-vl/gpt-4o 类）与 asr（whisper 兼容）模型，视频处理需服务器安装 ffmpeg
- **自定义报告**（十一期）：报告页/AI 工作台"自定义报告"入口——需求描述（1~2000 字）+ 知识库多选（不选全库）+ 附件上传（选中即传入幂等自动创建的"AI工作台资料库"，逐项轮询解析状态，全部就绪才可提交）；复用混合检索聚合上下文（≤4000 字符），生成完整独立 HTML 报告（内联 CSS、纯 CSS 图表、禁 JS），前端 iframe sandbox 预览防注入、按 format 下载 HTML/.md；**可一键导出 A4 PDF**（`GET /reports/{id}/pdf`，Playwright + 无头 Chromium 服务端打印，注入分页 CSS 防跨页断裂，中文文件名 RFC5987；仅 format=html 且 ready 可导，记 export/report 审计）
- **报告对话式编辑**（十一期）：`POST /reports/{id}/revise` 仅 custom 且 ready 可改（400/409 守卫）；指令输入 → revising 轮询 → 新 HTML 版本；旧版本存 params.revisions（cap 20），历史可"查看此版本/回到最新"；生成与修改均落审计
- **Skill 系统与工具调用**（十二期）：可插拔技能框架——内置技能（联网搜索 web_search：tavily/bing/duckduckgo 三通道；网页抓取 web_fetch：URL→纯文本）+ 自定义 API 技能（{{arg}} 占位符渲染 url/body，check_url_safe 拦截内网 SSRF）；管理端 /admin/skills 启停即存、敏感配置脱敏、测试对话框（失败不 500）、内置禁删；skills 表（租户内 name 唯一，DB 行覆盖内置默认）
- **对话 agent 循环**（十二期）：有启用 skill 时走 OpenAI function calling 工具循环（最多 3 轮，tool_calls 执行结果回注再调，单工具失败写原因继续，轮尽后不带工具要最终回答）；KB 未命中也可联网作答；模型不支持工具调用（Ollama 等）自动回退纯 RAG；**无启用 skill 时对话行为逐字节不变**；SSE 新增 tool 帧（sources 后、token 前），前端气泡上方展示"正在联网搜索…/已使用：联网搜索"工具标签；客户主页 AI 对话复用同一管线自动获得工具能力

- ~~录音/音视频自动转写~~ ✅ 十期已实现（ASR + ffmpeg 抽音轨）
- 文件夹删除纳入回收站（当前为物理删除）
- 客户主页"AI 对话"页签补有用/无用反馈与追问建议（九期遗留）

- 行为触发提醒（客户打开邮件/浏览官网埋点对接）与 AI 智能离线分析提醒
- 战略分析报告（多 Agent 协同）
- HyDE、按部门/日期等元数据过滤检索
- Redis 热点缓存、PostgreSQL 读写分离、MinIO/S3 对象存储（规模增长后按需引入）
