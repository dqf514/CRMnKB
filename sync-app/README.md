# 榜样知识库同步客户端

像 OneDrive 一样，把网页版「文档库」与本地文件夹双向同步；本地文件更新会自动触发服务端**知识库重新解析**（旧版本自动快照，可随时回滚）。

## 功能

- **双向同步**：本地新建/修改/删除 ⇄ 云端同步目录（本地根目录 ⇄ 云端「同步-电脑名」文件夹）
- **同步面板（OneDrive 式）**：点击托盘图标弹出面板——活动文件列表实时滚动（↑ 上传绿 / ↓ 下载蓝 + 逐字节进度条）、底部快捷按钮（打开文件夹/网页版/暂停/设置）
- **托盘动画图标**：同步时双箭头转圈；暂停灰显、离线橙点角标
- **设置面板**：服务器地址 / 账号切换 / 本地文件夹 / 云端目录名 / 轮询间隔，保存自动重启
- **打开网页版免登**：一次性 SSO 码，浏览器打开即进工作台
- **自动更新**：启动后及每 6 小时检查新版本，自动下载并无感重启完成更新
- **知识库联动**：本地改文件 → 上传 → 关联 KB 文档自动重新切片、重新向量化（旧版自动快照）
- **冲突保护**：两边同时改 → 本地版本保留为「(本机冲突 时间戳)」副本，云端版本落回原路径
- **移动跟随**：云端改名/移动 → 本地跟随；移出同步目录 → 本地删除；移入 → 自动下载
- **删除安全**：云端删除 → 本地删除（本地有改动则挪 `.sync-trash`）；本地删除 → 云端进回收站

## 快速开始

### 方式零：网页下载（推荐给同事）

网页版右上角头像菜单 → **下载同步 App**，双击按向导设置即可。
客户端**自动更新**：启动后及每 6 小时检查新版本，发现后自动下载并无感重启完成更新；托盘菜单也有「检查更新」可手动触发。

### 方式一：直接运行（开发/试用）

```bash
cd sync-app
pip install -r requirements.txt
python -m sync_app            # 首次启动弹设置向导
python -m sync_app --console  # 控制台模式（看日志调试用）
```

首次启动的设置向导（OneDrive 风格）：
1. **服务器地址**：如 `http://10.1.30.37:8100`
2. **用户名 / 密码**：网页版账号（签发 30 天长效 token，之后自动续期）
3. **同步文件夹**：默认 `C:\Users\<你>\榜样知识库`，可自选

### 方式二：打包 exe（分发给同事）

```bash
build.bat    # 产出 dist\榜样知识库同步.exe（单文件、无黑窗、自带图标）
```

双击 exe 即进入设置向导；把 exe 放开始菜单/启动文件夹可常驻。

## 同步规则

| 场景 | 行为 |
|---|---|
| 本地新建文件 | 上传到文档库（保留目录结构），并自动关联解析 |
| 本地修改文件 | 上传新内容 → 关联 KB 文档重解析（旧版自动存快照） |
| 本地删除文件 | 云端软删（网页回收站可恢复） |
| 云端新增/修改 | 下载到本地对应目录（每 30 秒轮询） |
| 云端删除 | 本地删除；若本地有未同步改动则挪 `.sync-trash/` |
| 双向同时修改 | 本地版本改名 `(本机冲突 时间戳)` 保留，云端版本为准 |

## 说明

- 配置存于 `config.json`（密码为本地明文，仅限内网环境使用；token 过期会自动重新登录）
- 同步状态存于 `<同步文件夹>/.sync-state/sync.db`，删除后重新全量对齐
- 忽略：临时文件（`~$*`、`.tmp`、`.part`）、隐藏文件、`.sync-trash`、冲突副本
- 单文件上限与网页一致（默认 100MB）
